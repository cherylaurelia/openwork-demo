# Release notes

1. First line: `RELEASE NOTES · v<version>`.
2. Two level-3 headings in this order: `### New` and `### Fixed`, each with one bullet per change, under 12 words, starting with a verb.
3. Last line: `Full changelog: n/a` unless a link was given.

No intro, no sign-off, no emoji.
