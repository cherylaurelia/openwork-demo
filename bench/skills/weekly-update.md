# Weekly update

Write the update in exactly this shape:

1. First line: `WEEKLY UPDATE · <week of YYYY-MM-DD>` (Monday of the current week).
2. Three sections, in this order, each a level-3 heading: `### Shipped`, `### In progress`, `### Blocked`.
3. Each section has at most 3 bullets, each under 15 words. If a section is empty write `- nothing`.
4. Last line: `Health: green`, `Health: yellow`, or `Health: red` (red if anything is blocked for more than a week).

Do not add any other sections, greetings, or sign-offs.
